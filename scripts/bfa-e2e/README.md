# BFA iOS simulator probes

Run the probes on macOS Apple Silicon with a booted iOS simulator. Install the
BFA native artifact with `node modules/kaleido-rgb/scripts/download-rgb-lib-ios.js`.
Set `SIMULATOR_UDID` to select a specific booted simulator if needed.

```sh
bash scripts/bfa-e2e/run-ios.sh
```

This checks the native library's decoding of a proxy v1 invoice generated by
WASM beta.4, then exercises local reopen and encrypted backup/restore with a
fresh unfunded Regtest wallet. It exercises Rate's staged restore and checks
that the same destination can be restored after a password or network mismatch.

To connect a fresh unfunded wallet to public Signet and reserve an encrypted
RGB witness invoice through Rate's default v1 proxy, run the same probe with
`--signet /path/to/new-invoice.json`. The native library checks the configured
Arbitrum One RPC during wallet startup. The file contains public invoice data.
Keep the invoice for decoder checks because the probe removes the test wallet
when it exits. The probe requires no BTC, RGB assets, or EVM funds.

To compare the new invoice with browser bindings, extract the pinned
`@utexo/rgb-lib-wasm` versions `1.0.0-beta.4` and `1.0.0-beta.3`, then run:

```sh
node scripts/bfa-e2e/verify-signet-invoice.mjs /path/to/new-invoice.json \
  /path/to/beta.4/package /path/to/beta.3/package
```

The optional cross-version diagnostic requires a separate Rate checkout with
the standard rgb-lib 0.3.0-beta.7 binding and simulator artifact already installed
by that checkout's pinned installer. Its archive is approximately 1.1 GB.
The runner validates both version pins and compiles each probe separately.

```sh
bash scripts/bfa-e2e/run-beta7-compat-ios.sh /path/to/standard-beta7-rate
```

Standard beta.7 creates a fresh unfunded Regtest wallet and exports an encrypted
backup. BFA reopens a closed copy of that wallet, then separately restores the
backup and compares the resulting descriptors and address index. Both probes
remove their private temporary directories on exit.

The BFA library's proxy migration marks standard beta.7 outgoing transfers in
`initiated` or `waitingCounterparty` as failed because proxy 0.2 and 1.0 are
incompatible. This offline diagnostic covers a clean wallet. Settled asset
balances and live transfers require funded test wallets and separate verification.
See [the native migration](https://github.com/UTEXO-Protocol/rgb-lib-bfa/blob/cafe66e49d58038a69dd05f8065e3fe96a9d1601/migration/src/m20261020_142324_proxy_v1.rs).
